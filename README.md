# Internet-shop 🛒

Этот мини-проект 5 летней давности представляет собой учебную попытку разработать интерфейс интернет-магазина, используя исключительно чистые технологии (Vanilla Web): HTML, CSS и JavaScript. Проект создан без использования тяжелых фреймворков и библиотек.

## 🚀 Как посмотреть проект

Сайт не требует установки на сервер или сборки. Чтобы начать работу, просто скачайте проект и откройте в браузере файл **`productsCategories.html`** — это главная отправная точка магазина.

## ✨ Ключевые особенности (Что реализовано)

*   **Переключение тем оформления:** В верхней панели сайта находится иконка «солнышка». Нажмите на неё, чтобы изменить цветовую тему сайта (светлая/тёмная). За эту магию отвечает чистый JS в файле `script.js`.
*   **Каталог и товары:** Навигация начинается со страницы категорий. Если вы зайдете в категорию **«Бытовая техника»**, то сможете увидеть карточки с реальными тестовыми товарами. 
*   **Умная корзина:** Проект умеет сохранять добавленные в корзину товары! Даже без базы данных приложение запоминает ваш выбор (магия `localStorage` и подтягивание данных из `products.json`). Проверить свои покупки можно на отдельной странице `cart.html`.

## 🛠 Технологический стек и структура

Согласно статистике репозитория, проект состоит из:
*   **HTML (46.6%)** — структура страниц (`productsCategories.html`, `products.html`, `product.html`, `cart.html`).
*   **JavaScript (38.5%)** — вся интерактивность, логика сохранения корзины и смена тем (находится в `script.js`).
*   **CSS (14.9%)** — стилизация интерфейса (`style.css`).

*Данные о товарах вынесены в отдельный файл `products.json`, что делает проект более гибким и приближенным к работе с реальным API.*
